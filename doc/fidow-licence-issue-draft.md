**Title:** Please consider adding a licence to this repository

The repository currently has no licence file. Under GitHub’s default terms that means the code isn’t cleared for reuse, modification, or redistribution in other projects (even with attribution). A number of people building on related tools would like to reference or share fixes cleanly.

No obligation, of course — just a polite ask so the community can build on this without legal ambiguity.

Thanks again for the research and the release.
